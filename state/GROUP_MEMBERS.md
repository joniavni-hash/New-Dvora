- פרופיל נוצר כשמזהים חבר חדש בקבוצה שרלוונטי

## שדות
```
### [שם]
- group: [שם קבוצה]
- phone: [אם ידוע]
- priority: vip / normal / low / ignore
- expects_response: fast / normal / no
- relationship_to_yoni: friend / client / family / colleague / acquaintance
- style_notes: [איך להגיב לו]
- notify_yoni: always / important / never

```
