# Model Routing Policy
<!-- Status: Active -->
<!-- Purpose: Minimize cost without significant quality loss -->

## עקרון
Sonnet כברירת מחדל. Opus רק כשבאמת צריך. Haiku למשימות פשוטות.

## מיפוי משימה → מודל

### Haiku (הכי זול — $4/M output)
| משימה | למה Haiku מספיק |
|--------|-----------------|
| סיכום קבוצות (אודיה) | ניתוח טקסט פשוט, פורמט קבוע |
| מעקב ארוחות / דיאטה | חישוב קלוריות, עדכון טבלה |
| תזכורות / HEARTBEAT | לוגיקה פשוטה, כן/לא |
| תגובות קצרות ("בוצע", "👍") | אין צורך בשיקול דעת |
| סיכום יומי | טקסט מובנה מ-state |
| Health check | סקריפט + דיווח |

### Sonnet (ברירת מחדל — $15/M output)
| משימה | למה Sonnet |
|--------|-----------|
| שיחה רגילה עם יוני | צריך הבנה, הקשר, טון |
| מחקר (צופית) | חיפוש, סינתזה, ניתוח |
| ניתוח מיילים | הבנת הקשר, ניסוח תשובה |
| משימות עבודה | ניתוח, כתיבה, תכנון |
| בניית תוכניות | חשיבה מורכבת |
| קוד / סקריפטים | דיוק טכני |

### Opus (רק כשצריך — $75/M output)
| משימה | למה רק Opus |
|--------|------------|
| ניתוח משפטי (חוזים, דין) | דיוק קריטי, ניואנסים |
| החלטות ארכיטקטורה מורכבות | חשיבה עמוקה, tradeoffs |
| כתיבה רגישה (מייל ללקוח/שותף חשוב) | טון מדויק, שיקול דעת |
| דיבאג מורכב שSonnet נכשל בו | fallback |

## כללי הפעלה

### דבורה (main agent)
- **ברירת מחדל: Sonnet**
- Opus: רק כשהמשימה ברשימת Opus למעלה
- אם יוני אומר "תעמיקי" / "תדייקי" / נושא משפטי → Opus

### Sub-agents
- **אודיה (קבוצות): Haiku**
- **צופית (מחקר): Sonnet**
- סוכנים עתידיים: Haiku כברירת מחדל, Sonnet אם צריך

### Escalation
- אם Sonnet נכשל (תשובה לא מספקת, יוני מתקן) → retry ב-Opus
- אם Haiku נכשל → retry ב-Sonnet

## חיסכון צפוי
| מצב נוכחי | מצב חדש | חיסכון |
|-----------|---------|--------|
| ~$680/חודש | ~$350-400/חודש | **~40-50%** |
