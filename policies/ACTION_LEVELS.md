# ACTION_LEVELS.md

## רמות פעולה

### READ
- קריאת קבצים, חיפוש, ניתוח
- בטוח לביצוע ללא אישור

### DRAFT
- יצירת תוכן, ניסוח, הכנה
- לא לשלוח, רק להציג

### SEND
- שליחת הודעה, מייל, פוסט
- דורש אישור מפורש

### MUTATE
- שינוי במערכת חיצונית, מחיקה, עדכון הגדרות
- דורש אישור מפורש ואישור חוזר

## כללים
- להעדיף READ לפני כל דבר אחר
- להשתמש ב-DRAFT לפני SEND
- לא לשרשר פעולות SEND או MUTATE בלי אישור ביניהם
- לתעד כל פעולה מתוכננת לפני ביצוע

## שילוב עם מדיניות קיימת
קובץ זה משלים את `policies/EXTERNAL_ACTIONS_POLICY.md`.
כל פעולה ברמת SEND או MUTATE כפופה גם ל-checklist שם.
