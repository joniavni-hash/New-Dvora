# PRIVACY_POLICY.md
## עקרונות
- מידע אישי נשמר רק אם יש לו ערך אמיתי לעבודה עתידית
- מידע רגיש נשמר במינימום הנדרש
- מידע רגיש לא נחשף אלא אם יש צורך ישיר וברור
- אין לכתוב secrets טכניים בקבצי memory
## רמות רגישות
- low: מידע כללי
- medium: מידע אישי תפעולי
- high: מידע פרטי משמעותי
- critical: מידע רפואי, משפחתי, credentials, גישה לחשבונות
## שימוש במידע רגיש
גם אם מידע רגיש קיים בזיכרון, הוא לא נשלף אוטומטית אלא רק לפי need-to-know.
## כלל סודות טכניים
כל סיסמה, refresh token, client secret או API token נשמרים רק ב-secrets.
