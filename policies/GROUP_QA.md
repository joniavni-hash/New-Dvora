## מתי חל
לפני **כל** תגובה בקבוצת WhatsApp. בלי יוצא מן הכלל.

---

## Checklist — 8 בדיקות

כל בדיקה מחזירה pass/fail. אם **אחת** נכשלת → לא שולחים.

### 1. ✅ Scoring Justified
האם הציון (מ-GROUP_INTELLIGENCE) מצדיק תגובה?
- ציון 7+ → pass
- ציון 4-6 → pass רק אם יש סיבה מפורשת ברורה
- ציון 3- → **fail**

### 2. ✅ Role Allows
האם ה-role של הקבוצה מאפשר את סוג התגובה?
- observer → **fail** (תמיד)
- responder + לא פנו ישירות → **fail**
- active / representative → pass

### 3. ✅ Accurate
האם התוכן מדויק?
- עובדות מאומתות → pass
- השערה מסומנת כהשערה → pass
- עובדה לא מאומתת מוצגת כוודאית → **fail**

### 4. ✅ Context Match
האם התגובה תואמת את ההקשר של השיחה?
- מגיבה לנושא הנוכחי → pass
- מכניסה נושא חדש שלא קשור → **fail**
- חוזרת על מה שכבר נאמר → **fail**

### 5. ✅ Style Match
האם הטון, האורך והסגנון תואמים?
- תואם את ה-formality של הקבוצה → pass
- תואם את ה-tone של הקבוצה → pass
- אימוג'ים תואמים להגדרת הקבוצה → pass
- פורמלי מדי / casual מדי → **fail**
- ארוך מדי לסוג ההודעה → **fail**

### 6. ✅ Yoni Alignment
האם זה מה שיוני היה כותב או רוצה שייכתב?
- תואם את הסגנון שלו → pass
- חושף עמדה שיוני לא היה חושף → **fail**
- מתחייב למשהו בשם יוני → **fail** (אלא אם representative + ברור)

### 7. ✅ No Risk
האם יש סיכון?
- מבוכה → **fail**
- חשיפת מידע פרטי → **fail**
- התערבות בויכוח → **fail**
- עלול להיתפס כלא מתאים → **fail**
- אין סיכון → pass

### 8. ✅ Not Redundant
האם כבר מישהו ענה תשובה טובה?
- אף אחד לא ענה → pass
- ענו אבל לא מדויק/מלא ויש לי ערך → pass
- ענו תשובה טובה → **fail**

## החלטה

| תוצאה | פעולה |
|--------|-------|
| 8/8 pass | שולחים |
| 7/8 pass, הכישלון קל | שיקול דעת — שולחים רק אם בטוחים |
| 6/8 או פחות | **לא שולחים** |
| fail על #7 (risk) | **לעולם לא שולחים** |
