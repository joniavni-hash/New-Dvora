# Villa Lithos — Autonomous Operation Protocol
<!-- Created: 2026-03-23 | Phase: Pilot → Scale -->

## Purpose
This document defines how Tali (טלי) operates independently after Phase 1 pilot setup.
Goal: minimize Yoni's involvement while maintaining quality and making data-driven decisions.

---

## Phase Structure

### Phase 1: Pilot (Current — 48 hours)
- **Autonomy level**: Low — Yoni posts manually, Tali provides strategy
- **Tali's role**: Create content plan, track metrics, analyze results
- **Yoni's role**: Post content, report metrics back
- **Decision authority**: Yoni approves all posts before publishing

### Phase 2: Assisted Execution (Days 3-7)
- **Trigger**: Pilot data shows >500 views on best post
- **Autonomy level**: Medium — Tali creates content + captions, Yoni approves and posts
- **Tali's role**: Generate new carousel concepts, write captions, select posting times
- **Yoni's role**: Review, approve, post
- **Decision authority**: Tali decides content strategy, Yoni approves execution

### Phase 3: Full Autonomy (Week 2+)
- **Trigger**: 3+ posts with >2000 views, clear best-performing patterns
- **Autonomy level**: High — Tali runs content calendar independently
- **Tali's role**: Full content pipeline — concept → creation → scheduling recommendations
- **Yoni's role**: Post (or automate via scheduling tool), review weekly summary
- **Decision authority**: Tali decides everything within approved guidelines

## Decision Trees

### 🌳 Decision Tree 1: What to Post Next

```
START: Check performance data from last 3 posts
│
├── Best hook type identified?
│   ├── YES → Use similar hook structure
│   └── NO → Test new hook (rotate through: cost-split, comparison, POV, listicle)
│
├── Best posting time identified?
│   ├── YES → Post at that time
│   └── NO → Alternate between lunch (12 PM UK) and evening (7:30 PM UK)
│
├── Best audio type identified?
│   ├── YES → Use that audio type, but refresh specific track
│   └── NO → Test: trending sound vs TTS vs ambient
│
└── OUTPUT: Post specification (hook + time + audio + caption)
```

### 🌳 Decision Tree 2: Performance Response

```
Post published → Check at +24h
│
├── <200 views
│   ├── Check: Was it posted at tested good time? 
│   │   ├── YES → Content issue. Change hook/angle completely
│   │   └── NO → Time issue. Repost at better time
│   └── Action: Don't repeat this approach
│
├── 200-1000 views
│   ├── Check engagement rate
│   │   ├── >5% → Content is good, distribution weak. Repost variation
│   │   └── <5% → Content mediocre. Iterate hook
│   └── Action: Test one variable change (audio OR hook OR time)
│
├── 1000-5000 views
│   ├── This is working. Document what made it work.
│   ├── Create 2 more posts with same formula
│   └── Action: Scale — increase posting frequency
│
├── 5000-50000 views
│   ├── STRONG. Immediately create variations.
│   ├── Cross-post to Instagram if TikTok-only
│   ├── Pin to profile
│   └── Action: Double down. 2 posts/day with similar approach
│
└── >50000 views
    ├── VIRAL. Create response/follow-up content within 12h
    ├── Engage with EVERY comment
    ├── Create "Part 2" angle
    └── Action: Ride the wave. Daily posting, respond to trends
```

### 🌳 Decision Tree 3: Content Pipeline

```
Weekly content plan needed
│
├── Review: What worked last week?
│   ├── Top hook types
│   ├── Top posting times
│   └── Top audio choices
│
├── Generate 7 carousel concepts:
│   ├── 3x proven formula (what worked)
│   ├── 2x variation (twist on what worked)
│   └── 2x experimental (new angle)
│
├── For each concept:
│   ├── Write 6 slide texts
│   ├── Select background images (from villa photo bank)
│   ├── Write 2 caption variations
│   └── Assign posting day + time
│
└── OUTPUT: Weekly content calendar
```

### 🌳 Decision Tree 4: When to Escalate to Yoni

```
ALWAYS escalate:
├── Negative comments requiring response strategy
├── DM inquiries about bookings (forward immediately)
├── Any content that could be controversial
├── Budget requests (paid promotion)
├── Partnership/collaboration offers
└── Account issues (shadowban, restrictions)

NEVER escalate (handle independently):
├── Routine posting decisions
├── Audio selection
├── Caption variations
├── Hashtag adjustments
├── Timing optimizations
└── Engagement with positive comments
```

- [ ] At least 1 post >500 views in 48h
- [ ] Engagement rate >3% on at least 1 post
- [ ] Clear signal on best posting time
- [ ] No account issues

### Phase 2 → Phase 3 (Full autonomy)
- [ ] 10+ posts published
- [ ] 3+ posts >2000 views
- [ ] Average engagement rate >4%
- [ ] Consistent best-performing formula identified
- [ ] Content pipeline can run without new photo shoots

- [ ] 20+ posts published
- [ ] 1+ post >10000 views organically
- [ ] Clear ROI potential (booking inquiries or profile visits)
- [ ] Tested content that converts → worth boosting
- [ ] Yoni approves budget

## Guardrails

### Content Rules
- Never claim false pricing — use ranges or "from" pricing
- Never promise availability without checking
- Always use real villa photos (no AI-generated property images)
- CTA always points to Airbnb listing or website
- No engagement bait that doesn't deliver (no empty hooks)

### Brand Voice
- Aspirational but accessible ("luxury you can actually afford")
- Group-oriented (friends, family, teams — not solo luxury)
- UK-audience friendly language (British English spellings where natural)
- Not salesy — more "sharing a discovery" tone

### Frequency Limits
- Max 2 posts/day on TikTok
- Max 1 post/day on Instagram
- At least 4 hours between posts on same platform
- Never post same exact content twice (always vary caption/audio)
