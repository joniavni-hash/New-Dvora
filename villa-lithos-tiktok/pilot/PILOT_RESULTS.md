### Content Production Pipeline
1. **Hook selection** → Rotate from 10-hook queue based on performance data
2. **Photo selection** → Map villa photo bank to slide positions
3. **Text overlay** → Use `node-canvas` script from larry-system
4. **Upload** → `npx postiz upload <file>` per slide
5. **Draft creation** → `npx postiz posts:create` with platform settings
6. **Yoni review** → Add audio (TikTok), approve, publish
7. **Analytics check** → After 24h: `npx postiz analytics:post <id>`
8. **Loop** → Feed results back into hook selection

### Escalation Rules
**Always notify Yoni:**
- Booking inquiries via DMs
- Viral post (>10K views) — capitalize immediately
- Negative comments needing response
- Account issues or restrictions

**Handle autonomously:**
- Routine posting decisions
- Caption/hashtag variations
- Posting time optimization
- Analytics monitoring
